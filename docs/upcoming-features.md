# Upcoming Features

## Daily Lotto Results

Track and display daily lottery results with historical data and notifications.

**Planned Features:**
- Daily lottery result tracking and display
- Historical data archive
- Notification system for result updates
- Search and filter functionality

## Helper Assistant

Manage domestic helper records including attendance tracking, leave balance, monthly salary, and employment history.

**Planned Features:**
- Attendance tracking with daily logs
- Leave balance management (days off remaining)
- Monthly salary calculation and records
- Contract and Personal details
- Payment schedule tracking
- Submitted requirements

## Dashboard Widgets

Grow the customizable dashboard (today: users choose which app buttons to show, saved in auth metadata under `dashboard_hidden_apps`) into widgets.

**Planned Features:**
- Overview widget per module, as an alternative to the button: Notes (recent notes + count), Passwords (recently updated names, never secrets), Cards (expiring soonest), Grocery (active lists, items left), Rentals (SOAs due or overdue, rooms occupied; best after rent payments are recorded), Invoices (recent invoices), Government (latest records), Career/Profile (completeness, latest item), Friends (count, pending requests)
- Storage stays button-only
- Per module choice of Overview, Button, or Hidden
- Drag and drop to reorder, with sizes (small button, medium or wide overview) on a responsive grid, via a Customize mode
- Layout saved to the account so it follows the user across devices; mobile reads the same layout later

## Dashboard A–Z Layout

Sort the dashboard tiles alphabetically and group them by first letter, like a phone's contacts list, with a letter scroll bar to jump between groups.

**Planned Features:**
- Tiles sorted A–Z by name, under a letter heading per group (A, C, F, G, …), showing only letters that have tiles
- A vertical letter bar on the right edge: tap or drag a letter to jump to its group, with the current letter shown large while dragging
- Hidden tiles (from Customize) are left out of the groups and the letter bar
- Mobile first; on web, the letter bar can be a row of letter links above the grid
