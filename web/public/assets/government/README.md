# Government marks

These marks identify the issuer or ID program in a user's personal records.
The app is not an agency service. Original colors and proportions are preserved;
larger PNGs are downscaled to a maximum dimension of 256 pixels.

| File | Source |
| --- | --- |
| pag-ibig.png | https://www.pagibigfundservices.com/OnlineMembershipRegistration/Content/Images/logo.png |
| philhealth.png | https://www.philhealth.gov.ph/images/philhealth-official-logo.png |
| bir.png | https://verify.bir.gov.ph/logo192.png |
| sss.png | https://www.sss.gov.ph/wp-content/uploads/2024/09/sss-logo-header-2.png |
| national-id.png | https://verify.philsys.gov.ph/static/images/idnatin.png |
| umid.png | https://en.wikipedia.org/wiki/File:UMID_Philippine_seal.svg |

The UMID seal is a public-domain reproduction attributed to the Government of the
Philippines, obtained from the image above rather than assigning an unconfirmed
issuer. Matching assets are bundled in `mobile/assets/government/`.
